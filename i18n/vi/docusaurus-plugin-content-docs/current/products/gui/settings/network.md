# Mạng

Phần này mô tả cách cấu hình các thiết lập mạng, bao gồm proxy và thời gian chờ kết nối.

![Mạng Settings](/img/products/gui/settings/network-settings.png)

## Proxy Server (Máy chủ Proxy)

Nếu mạng nội bộ hoặc quốc gia của bạn giới hạn quyền truy cập vào các cổng kết nối (endpoint) của OKX, bạn có thể định tuyến tất cả lưu lượng API qua một máy chủ proxy tùy chỉnh.

- **Enable Proxy (Bật Proxy)**: Tích chọn ô này để chuyển hướng các yêu cầu API qua máy chủ proxy đã cấu hình.
- **Address (Địa chỉ)**: Địa chỉ IP hoặc tên miền của máy chủ proxy của bạn.
- **Port (Cổng)**: Số cổng kết nối của máy chủ proxy.

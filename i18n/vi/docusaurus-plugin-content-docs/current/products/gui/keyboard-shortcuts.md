# Phím Tắt (Keyboard Shortcuts)

Platinum Trade cung cấp hàng loạt các phím tắt và thao tác chuột nhằm giúp bạn điều hướng nền tảng, phân tích biểu đồ và thao tác giao dịch nhanh chóng và hiệu quả hơn.

## Điều hướng chung

| Phím Tắt | Hành động |
| :--- | :--- |
| <kbd>F11</kbd> | Bật/tắt chế độ Toàn màn hình (Fullscreen) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Mở cài đặt (Options) |
| <kbd>F1</kbd> | Mở hộp thoại thông tin / Trợ giúp (About) |
| <kbd>Alt</kbd>+<kbd>F4</kbd> | Thoát ứng dụng |

## Hiển thị & Thu phóng biểu đồ

| Phím Tắt | Hành động |
| :--- | :--- |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> | Phóng to biểu đồ (Zoom In) |
| <kbd>Ctrl</kbd>+<kbd>-</kbd> | Thu nhỏ biểu đồ (Zoom Out) |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | Đặt lại tỉ lệ thu phóng mặc định (Reset Zoom) |
| <kbd>Alt</kbd>+<kbd>1</kbd> | Chuyển sang biểu đồ Thanh (Bar Chart) |
| <kbd>Alt</kbd>+<kbd>2</kbd> | Chuyển sang biểu đồ Nến (Candlestick Chart) |
| <kbd>Alt</kbd>+<kbd>3</kbd> | Chuyển sang biểu đồ Đường (Line Chart) |

## Dữ liệu & Giao dịch

| Phím Tắt | Hành động |
| :--- | :--- |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | Thêm mã tiền tệ mới vào Market Watch (Add Symbol) |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Mở biểu đồ Sổ lệnh (Bid/Ask Chart) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> | Mở trình quản lý dữ liệu lịch sử (History Manager) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Mở trình quản lý Plugin Chỉ báo (Indicator Plugin Manager) |

## Công cụ vẽ & Thao tác chuột

| Phím tắt / Cử chỉ | Hành động |
| :--- | :--- |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Sao chép đối tượng vẽ đang chọn |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Dán đối tượng vẽ |
| <kbd>Del</kbd> | Xóa (các) đối tượng vẽ đang chọn |
| **Nhấp đúp chuột (Double Click)** | Chỉnh sửa thuộc tính đối tượng vẽ |
| **Ctrl + Click** | Chọn nhiều đối tượng cùng lúc |
| **Click vào vùng trống** | Bỏ chọn tất cả đối tượng |

---

*Mẹo: Việc làm quen và sử dụng thành thạo các phím tắt này sẽ giúp bạn tối ưu hóa đáng kể tốc độ phân tích kỹ thuật và xử lý tình huống khi giao dịch thực tế.*

# Tổng Quan

App Platinum Trade cung cấp quy trình giao dịch OKX, biểu đồ, indicator, backtest và khả năng truy cập tính năng theo license.

## Năng Lực Cốt Lõi

- Thiết lập thông tin xác thực API và kiểm tra kết nối.
- Thực thi chiến lược ở chế độ paper và live (phụ thuộc quyền license).
- Hỗ trợ bản địa hóa cho tài nguyên tiếng Anh và tiếng Việt.
- Tích hợp cơ chế cập nhật qua hook khởi động Velopack.

## Ghi Chú Bảo Mật Và Riêng Tư

- Tài liệu sản phẩm này không mô tả cấu trúc mã nguồn nội bộ.

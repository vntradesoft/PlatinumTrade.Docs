# Tài liệu API tự động tạo (DocFX)

Để xem toàn bộ kiến trúc namespace, các class public, interface, phương thức và thuộc tính trong assembly `Pt.Okx.Sdk`, vui lòng tham khảo tài liệu DocFX được tự động tạo.

Tài liệu này được xây dựng trực tiếp từ các chú thích XML trong mã nguồn C# và cung cấp:

- **Hệ thống phân cấp namespace đầy đủ** — duyệt qua `Pt.Okx.Sdk.Clients`, `Pt.Okx.Sdk.Enums`, `Pt.Okx.Sdk.Strategy`, v.v.
- **Chữ ký phương thức hoàn chỉnh** — bao gồm các overload, tham số generic và kiểu trả về
- **Chú thích XML (XML comments)** — phần remarks, ví dụ và liên kết chéo từ mã nguồn
- **Cây kế thừa** — phân cấp lớp và triển khai interface
